# SD法 感性評価システム

## 起動方法

**音源機能（ピックに音声ファイルを添付する機能）は IndexedDB を使っています。**
ブラウザによっては、`index.html` をダブルクリックしてそのまま開く（`file://` で開く）と、
IndexedDB がブロックされて音源が保存・再生できないことがあります
（画面には赤字で「⚠ 音源を読み込めませんでした」と表示されます）。

音源機能を使う場合は、以下のように簡易サーバー経由で開くことを強く推奨します。
（音源を使わない場合は、`index.html` を直接開くだけで問題なく動作します。）

### 方法1：Python がある場合

1. このフォルダをターミナルで開く
2. 以下を実行
   ```
   python3 -m http.server 8000
   ```
3. ブラウザで `http://localhost:8000` を開く

### 方法2：Node.js がある場合

```
npx serve .
```
と実行し、表示されたURL（例：`http://localhost:3000`）を開く

### 方法3：VSCode を使う場合

拡張機能「Live Server」をインストールし、`index.html` を右クリック →
「Open with Live Server」

### 方法4：実験用PCに常設する場合

上記のいずれかの方法でずっと立ち上げておくか、Web上（GitHub Pages・Vercelなど）に
アップロードして常時公開しておくと、実験のたびにサーバーを起動する手間がなくなります。

## データの保存場所

- 評価項目・ピック・回答・設定 → ブラウザの **localStorage**
- 音源ファイル → ブラウザの **IndexedDB**

どちらも「そのブラウザ」に保存されます。別のPC・別のブラウザに移す場合は、
管理画面の「バックアップ」タブから設定・回答データを書き出し／読み込みしてください
（※音源ファイル自体はバックアップに含まれないため、別PCで使う場合は音源を再アップロードしてください）。

## フォルダ構成

```
index.html
css/style.css
js/
  utils.js     共通ユーティリティ
  storage.js   localStorage層 + バックアップ
  audio.js     IndexedDBによる音源保存
  state.js     状態管理・プロジェクト管理・テンプレート管理
  chart.js     SVGレーダーチャート
  report.js    PDFレポート画面
  survey.js    被験者側画面
  admin.js     管理画面
  main.js      起動・画面切り替え
```
